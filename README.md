# iBrain

Free native macOS AI chat app built with Swift and SwiftUI. The app uses Ollama for local models by default, with optional OpenAI and Anthropic API support using a key supplied by the user.

- macOS source and build notes: [`macos-source/`](macos-source/)
- Requirements: macOS 14 or later; Ollama is required for local model chat
- Current release status: source is public; no compiled app download is published yet

The marketing page is a project overview. Feature availability and setup requirements are documented in the source README.
