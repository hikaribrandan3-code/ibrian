Local by default

Local Ollama chat runs on your Mac. If you enable cloud mode, prompts go to the OpenAI or Anthropic provider you choose.

✈️

Offline local chat

After Ollama and a model are installed, local chats can run without an internet connection.

How It Works

Three steps to private AI.

01

Install iBrain

The source is public on GitHub. A compiled app download is not published yet.

02

Download a Model

Install or start Ollama, then iBrain offers to download its recommended model. Other installed Ollama models can be selected in the app.

03

Start Chatting

Open iBrain, choose an installed model, and chat. Prompts stay on your Mac in local mode; cloud mode sends them to the provider you select.

Frequently Asked Questions

How much does iBrain cost?
iBrain is free. The source is public; a compiled download is not published yet.
How does offline mode work?
iBrain connects to a local Ollama instance running on your Mac. AI models are downloaded to your machine and processed locally using your CPU/GPU. No internet is required after the initial model download.
Can I use cloud AI instead?
Yes. iBrain supports optional cloud APIs — bring your own Anthropic (Claude) or OpenAI (GPT) key. This is useful for more advanced models, but completely optional. All local features work without it.
Does it work on Intel Macs?
iBrain requires macOS 14 or later. The current app package was built on Apple Silicon; Intel compatibility has not been verified.
Is iBrain part of iSuite Office?
Yes. iBrain is a free standalone app in the iSuite family. It also integrates with iVoz for voice-to-AI workflows.
